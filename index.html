RoFrame documentation

RoFrame is a TypeScript-first, modular Roblox framework with a lifecycle kernel, typed networking, server-authoritative state and optional React-Lua UI modules.

Getting started​

  • Packaging and releases: packages, installation, Changesets and CI.
  • Development workflow: installation, builds, validation and Rojo.
  • Coin Hunt demo: launch the integration demo in Roblox Studio.

Core​

  • Kernel: dependency injection and lifecycle contracts.
  • Components: behavior attached to tagged Roblox Instances.
  • Networking: typed messages and server validation.
  • Stores: state, scopes, subscriptions and replication.
  • Persistence: DataStores, migrations and session safety.
  • Player lifecycle: profiles, readiness and Characters.
  • UI: React roots, themes, hooks, routing and notifications.
  • Core utilities: scheduling, registries and native wrappers.
  • Platform services: permissions, commands and Roblox services.
  • Modules: discovery, configuration and lifecycle.
  • Developer tools: profiling and development diagnostics.

Optional packages and integration notes​

  • Cartoon UI: optional components, interaction and animation.
  • Camera: independent package skeleton and planned dependency direction.
  • Animator: independent package skeleton and future timeline ownership.
  • Cartoon UI audit: visual baseline and component mapping.
  • Demo Core findings: issues found during Coin Hunt integration.

API reference​

  • Generated API reference: public Core, UI and Cartoon UI exports, including functions, classes, interfaces, parameters and return types.
